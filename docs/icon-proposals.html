0. 현재 상태 진단

Sidebar.tsx의 메뉴 아이콘은 유니코드 문자(□ ▤ ☑ …)를 그대로 출력하고 있습니다.

  • 유니코드 글리프는 폰트가 그리는 문자라서 굵기·크기·베이스라인이 모두 제각각 (☑는 가늘고, ▣는 꽉 차 보임)
  • OS·폰트 환경에 따라 다르게 렌더링 — 일부 글리프는 이모지로 대체될 수도 있음
  • 앱 아이콘(흰 배경 + L 마크)은 macOS 표준 squircle 규격이 아니어서 Dock에서 이질적
  • tray-icon이 32px 단일 해상도 → Retina에서 흐릿하게 보일 수 있음

1. 앱 아이콘 시안 (4종)

모두 macOS 표준 squircle 비율(1024px 캔버스 기준 여백 포함)을 따릅니다. "LinkWork = 일을 잇는다"는 의미로 체인 링크와 WBS 노드 연결을 핵심 모티프로 사용했습니다.

V1 · 그라디언트 미니멀

Link Gradient

인디고→바이올렛 그라디언트 위 흰색 체인 링크. 2026 트렌드 리서치에서 생산성 앱에 가장 권장되는 "미니멀 + 그라디언트" 조합. 어느 크기에서도 실루엣이 선명함.

V2 · WBS 노드

Node Path

기존 "L" 아이덴티티를 계승하되, L자를 WBS 작업 경로(노드+연결선)로 재해석. 다크 네이비 배경이라 다크모드 Dock에서 고급스러움. "프로젝트 관리 도구"라는 정체성이 가장 잘 드러남.

V3 · 글래스모피즘

Glass Link

macOS 26 스타일의 프로스트 글라스 레이어. 트렌디하고 프리미엄한 인상이지만, 16px 축소 시 유리 패널 디테일이 뭉개지는 약점이 있음 (아래 16px 비교 참고).

V4 · 웹툰

Comic Chain

굵은 잉크 아웃라인 + 플랫 컬러 + 만화식 하이라이트/효과선. 개성과 친근함은 최고지만 "업무 관리 도구"의 톤과는 거리가 있어, 개인용 앱으로 쓸 때 재미를 주는 선택지.

macOS Dock 시뮬레이션 — 다른 앱들 사이에서의 조화 확인용

2. 메뉴 아이콘 스타일 (4종 × 9개 전체 세트)

모든 스타일이 24×24 그리드, 동일 모티프로 제작되어 크기·정렬 문제가 사라집니다. Variables는 ⚙(설정으로 오해됨) 대신 슬라이더 모티프로 교체했습니다.

3. 실제 사이드바 적용 미리보기

현재 Sidebar.tsx와 동일한 레이아웃(bg-gray-900, Dashboard 활성 상태)에 각 스타일을 적용한 모습입니다.

4. 크기 검증 (16 / 20 / 24px)

사이드바 아이콘은 보통 16~20px로 렌더링됩니다. 작은 크기에서도 형태가 유지되는지 확인하세요.

5. 종합 추천

스타일강점약점적합도
A. 라인밀도 높은 사이드바·대시보드의 표준. 텍스트와 시각적 무게가 균형. Lucide 등 라이브러리로 손쉽게 확장아주 작은 크기(14px 이하)에서 가독성 저하★★★★★ 기본 권장
B. 솔리드작은 크기·다크모드에서 인식 속도 가장 빠름. 활성(선택) 상태 표현에 최적9개가 모두 솔리드면 사이드바가 무거워 보임★★★★☆ 활성 상태 전용 추천
C. 듀오톤차분하면서 표현력 있음. 브랜드 컬러를 면으로 은은하게 노출16px 이하에서 면이 뭉개짐. 구현 복잡도 약간 상승★★★☆☆ 차별화 원할 때
D. 웹툰개성·친근함 최고. 컬러로 메뉴 구분이 즉각적업무 도구 톤과 거리. 비활성 상태 처리(채도 낮춤)가 필요★★★☆☆ 캐주얼 컨셉일 때

💡 권장 조합: 메뉴 아이콘은 A. 라인(기본) + B. 솔리드(활성 상태) 하이브리드 — Apple·Linear·Slack이 쓰는 패턴으로, 선택된 메뉴가 즉각 구분됩니다. 앱 아이콘은 V1(무난+트렌디) 또는 V2(정체성 계승)를 권장합니다. 트레이 아이콘은 V1의 체인 글리프를 흑백 템플릿 이미지(16/32px @1x·@2x)로 추출하면 메뉴바 라이트/다크 모드에 자동 대응됩니다.
